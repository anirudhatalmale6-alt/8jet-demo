# 8JET — maquette transfert aéroport de prestige

Une seule page, **96 aéroports**, feuilletable comme un livre. **8JET est un nom
provisoire.**

Choisissez un aéroport dans l'index de gauche : la page de droite se recompose.
Choisissez un véhicule et un niveau de protection : le devis se recalcule.

## Ce qui est réel

Les 96 aéroports, leurs codes IATA, leurs villes et leurs pays — 50 pays,
7 régions. La flotte est **exclusivement Mercedes**, six modèles, avec leurs
capacités réelles en configuration chauffeur.

## Ce qui est indicatif, et annoncé comme tel sur la page

Les distances au centre-ville, les temps de trajet et les tarifs. Un temps de
trajet dépend de l'heure et du trafic ; un tarif dépend de contrats. Les prix
sont **dérivés d'une formule**, pas d'une table de 96 × 6 × 3 valeurs tapées à
la main — une table donnerait l'illusion d'un barème réel. Le jour où la vraie
grille arrive, on remplace la fonction.

## Sur l'option sécurité

La page décrit trois niveaux et s'arrête là où le droit commence : **aucune
promesse de véhicule blindé à une norme précise, aucune mention d'arme**. Le
port d'arme d'un agent de protection est réglementé pays par pays et n'est pas
autorisé dans la majorité des 96 destinations listées. Annoncer publiquement une
capacité illégale à l'arrivée fait perdre le client et l'autorisation
d'exercer. Toute mission protégée est donc confirmée après étude de la
destination.
